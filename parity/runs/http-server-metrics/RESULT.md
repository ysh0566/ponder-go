# HTTP 服务、端口与指标

固定上游 14 条 HTTP 服务用例、1 条端口探测和 3 条指标用例，在 PostgreSQL 与 PGlite 上各通过 18 条。Go 端在两个后端分别创建数据库，验证就绪标志由 0 改为 1 后的 HTTP 响应。通过实际 TCP 连接检查双栈监听、连接复用、关闭耗时和端口重新绑定。

| Go 测试范围 | 普通模式 | 竞态模式 |
| --- | ---: | ---: |
| indexing | 66 | 66 |
| metrics | 4 | 4 |
| query | 40 | 40 |
| store | 72 | 72 |

query 与 metrics 为完整包。indexing 和 store 验证索引服务、ORM、预取和缓存回归。两种模式均无失败或跳过。现有 SDK 的 SQL/SSE 集成在两个数据库上通过。整个模块通过编译与静态检查。

服务可读取数据库的就绪状态，使用注册的路由模板作为 HTTP 指标标签。索引计数在采集时合并，重置事件进度时保留缓存和数据库操作累计值。共享注册表的集成用例通过真实事件处理和两次行读取验证一次缓存未命中、一次命中和两次查询。
