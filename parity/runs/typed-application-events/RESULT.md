# 类型化处理函数事件

固定上游的 `virtual.test-d.ts` 通过全部 22 条。本阶段移植其中 8 条事件结构用例，使用 16 项原始双向类型断言。Go 编译器对照外部调用方根据原始断言声明的类型，另行拒绝缺少的字段及绑定到错误事件的处理函数。
