# GraphQL 实体查询与 HTTP 中间件

固定源文件的 44 条用例在 PostgreSQL 和 PGlite 上分别通过。本阶段移植其中 15 条，覆盖按主键读取单个实体、复合键、字段别名和类型、检查点元数据，以及全部 7 条 HTTP 中间件用例。两个后端分别观测了 18 次原始请求，按原表、数据、文档和路由通过 Go 服务重放。

Go 服务通过只读事务查询实际数据库。补充用例通过索引写入器提交超过 JavaScript 安全整数范围的数值，随后用 GraphQL 变量、别名、片段和具名操作读取完整数值及区块进度。独立的上游类型查询证实，列内声明的枚举主键保留枚举类型，表级复合主键的枚举参数使用字符串。两个后端均验证了枚举值输出。

HTTP 中间件支持应用自定义挂载路径，检查操作 token 数、深度和别名数量。GET 返回上游交互式查询页，其浏览器资源沿用上游 CDN 地址。在修复前，16 个并发请求触发了枚举映射的读写竞态。改为在服务构造时初始化映射后，同一并发回归在竞态检测下连续通过 25 次。模块编译和静态检查均通过。
