# 异步队列与 RPC 传输验证

`async.NewQueue` 在有并发名额时立即调用 worker。任务按进入顺序排队，请求频率按自然秒计数。多个队列使用同一个 `async.Loop` 时会轮流补充任务。调用 `Future.Await(ctx)` 会驱动该循环，也可以用 `Loop.Run(ctx)` 持续处理回调。worker 返回 future，回调内需要把控制权交还给循环。清空队列时可以给 `Clear` 提供回调，处理被移除任务的结果。

`rpc.NewRateLimitedRequester` 接收已配置的异步传输，自行驱动队列。取消等待中的请求会移除它；在途请求完成后才归还输出对象。`rpc.NewLoadBalancedRequester` 按轮询顺序调用下游。
