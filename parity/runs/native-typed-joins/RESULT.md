# Typed model joins in Go callbacks

The Go model generator emits column descriptors for both typed codegen modes. A join predicate binds its column names, row types and shared Go value type at compile time. Inner joins return two typed rows. Left joins return an optional right row. The query reads both models in the active business transaction and uses the ordinary SQL cache flush and row decoders. In Isolated ordering it scopes both sides to the event chain. [Usage](../../../docs/USAGE.md#在-go-回调中连接两张表) · [Go API](../../../orm/join.go) · [Store operation](../../../store/indexing_join.go)

The native tests cover two distinct tables with buffered inserts, JSON integers above JavaScript's safe range, byte sequences and nullable array elements. Callback failure and chain rollback remove the joined rows. Self joins exercise custom codecs, a nullable key, multiple matching rows and a second predicate. Revoking the callback context prevents reuse. The compile checks cover distinct row result types, missing columns, mismatched column types and nullable results. The generator preserves an existing enum name that collides with the new column binding. [Test cases](../../../orm/join_test.go)

## Reproduction

Provide the repository's PostgreSQL and PGlite test prerequisites and run the following from the module directory.

```sh
go test -count=1 ./orm
go test -race -count=1 ./orm
go test -count=1 -run '^(TestSourceCallbackContext|TestDatabaseBindingCapabilities|TestDatabaseUnboundOperationsReject|TestDatabaseBindingRevocationJoins|TestORMIsolatedComposite)$' ./config ./indexing ./store
go test -race -count=1 -run '^(TestSourceCallbackContext|TestDatabaseBindingCapabilities|TestDatabaseUnboundOperationsReject|TestDatabaseBindingRevocationJoins|TestORMIsolatedComposite)$' ./config ./indexing ./store
```
