# GraphQL 表查询、过滤与游标

固定的两份上游 GraphQL 测试文件在 PostgreSQL 和 PGlite 上各通过 44 条。本阶段新增 17 条原版用例的 Go 映射。两个后端分别记录 45 个实际 GraphQL 请求及其完整响应，另核对了 104 个过滤输入字段的名称和类型。Go 在两个后端重放相同查询，并逐字比较原版返回的游标。

| Go 包 | 普通模式 | 竞态模式 |

| graphql | 70 | 70 |

过滤条件和游标值由数据库参数绑定。排序保留主键作为排序值相同时的次序。选择总数时，同一条只读 SQL 读取当前页和总数。补充用例覆盖变量中的显式空值、含单引号的键、超大整数、片段中的总数字段和偏移量。固定的 GraphQL 依赖版本支持原版查询里的显式空值。枚举并发回归在该依赖下重复通过 25 次。模块构建和静态检查通过。
