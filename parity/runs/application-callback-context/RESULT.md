# 处理函数的上下文

固定版本上游的 22 条声明均已有 Go 映射。本阶段补齐 4 条，包含 11 项类型断言和原注册函数内的 10 处属性读取。外部调用方编译并运行了具有源链、事件、合约和数据库类型的注册函数。

数据库用例通过生成的模型在 PostgreSQL 和 PGlite 实际执行了缓存写入、查询和立即执行的 SQL 写入，并检查旧写入句柄在事务结束后失效。上游合约类型测试本身使用简短地址 `0x` 与 `0x69`，在本地测试中按原值核对 ABI 顺序、地址及可选边界。链客户端验证了原断言列出的 7 个方法，并对照 viem 检查 ENS 请求的完整 calldata、区块号、命中、空值和错误处理。ENS 测试使用本地已知应答。
