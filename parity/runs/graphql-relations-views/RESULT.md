# GraphQL 关联查询与视图

本阶段完成 9 条关联查询及 3 条视图用例。PostgreSQL 和 PGlite 上各重放了 13 个原始请求，校验完整响应。在三个实体关联到两个主键的原版用例中，Go 对父表和关联表分别只执行了一次查询。固定上游的两个 GraphQL 测试文件各后端通过 44 条。至此 37 条查询及 7 条 HTTP 声明全部有双后端 Go 映射。

同一请求内的关联字段合并数据库读取。补充回归验证了复合连接键、同字段的多个别名，以及两次请求之间更新数据后的可见性。视图用例从真实 SQL 视图读取，覆盖聚合列的公开字段名、过滤约束和偏移量。存储层在两个后端重跑了 schema 对象与数据库生命周期相关用例。模块构建、静态检查及重复 25 次的并发回归均通过。
