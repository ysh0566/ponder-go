# 应用配置与工厂参数

固定上游的 10 条配置运行用例和 4 条工厂类型用例全部通过。TypeScript 5.4.5 校验了两个精确返回类型断言。逐处移除原文件的错误抑制后，编译器在预期行报告两次 TS2353 和一次 TS2322。

外部 Go 调用方通过公开 API 声明链、账户、合约、多个事件过滤器和逐链覆盖，逐项比对了声明数据、配置指针身份及交给原生构建器的数据。Go 调用方显式声明链 ID 和字符串的字面值类型。编译反例覆盖了额外字段、把 ABI 函数当作事件以及跨事件引用参数。
